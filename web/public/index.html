Agents & MCP

Let autonomous agents drive the full assess → find → plan → apply → rollback loop
Remediation: DISABLED
MCP server
Ready (stdio)

A Model Context Protocol server exposes FlareInspect as tools so any MCP-aware agent (Claude Code, Hermes, OpenClaw) can connect over stdio.

Add to your MCP client config:
{ "mcpServers": { "flareinspect": { "command": "node", "args": ["/path/to/flareinspect/mcp/server.mjs"] } } }

No Cloudflare token is stored on the server. The agent passes its token when calling flareinspect_assess; results & reports are then read back by assessmentId with no token (flareinspect_get_assessment, flareinspect_list_findings, flareinspect_get_report).

Live remediation gate
DISABLED

apply_remediation and rollback are gated off. They require the server to be started with the gate enabled and an edit-scoped token.

Enable on the server (then restart):
FLAREINSPECT_ALLOW_REMEDIATION=true FLAREINSPECT_EDIT_SCOPE=<opaque-secret-or-jwt>

For safety this cannot be toggled from the browser. Read scopes (assess, findings, plan) work without it.
