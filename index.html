Features

Everything you need to harden
your Cloudflare infrastructure.

From a single CLI command to a full SIEM-integrated security operations workflow.

50+ Security Checks
Deep inspection across DNS, SSL/TLS, WAF, Zero Trust, Bot Management, Workers, Access, DDoS, CASB, and more.
Core
Resource Graph
Typed node/edge graph of your entire Cloudflare account — the single source of truth for posture, attack paths, and SIEM enrichment.
v2.0
Attack-Path Detection
Five rule-based detectors chain individual findings into attack paths — exposed-origin, weak-transport, open-access-app, and more.
v2.0
MCP Agent Support
An MCP server exposes FlareInspect as tools to any MCP-aware agent — Claude Code, Hermes, OpenClaw — over stdio.
v2.0
SIEM Streaming
Ship findings to Elasticsearch (ECS) or Splunk HEC with attack-path enrichment. Packaged Kibana and Splunk apps included.
v2.0
AI-Assisted Remediation
Connect Ollama, Claude, or OpenAI to generate a remediation plan. Every apply is backed up and reversible via rollback.
v2.0
Compliance Mapping
Every check maps to CIS Benchmark, SOC 2, PCI-DSS, and NIST CSF controls. Generate compliance reports in seconds.
Core
Drift Detection
Compare any two assessments with flareinspect diff to surface regressions and improvements over time.
Core
Web Dashboard
A local SPA with score visualization, posture map, filterable findings, compliance reports, and assessment history.
Core
Attack paths

See exactly how attackers
would reach your origin.

Five rule-based detectors analyze your resource graph to find chains of misconfiguration that lead to high or critical exposure.

Exposed origin
Finds paths from the internet to your origin IP when WAF and proxy settings are misconfigured.
Weak transport chain
Traces HSTS gaps, outdated TLS versions, and disabled encryption rewrites into a single attack path.
Remediable paths
Each detected path carries a list of remediableCheckIds so the AI planner can fix it end-to-end.
